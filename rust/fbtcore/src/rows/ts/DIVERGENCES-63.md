# Divergences of the Angular half, #63 on

Signed off, as every entry of [DIVERGENCES.md](DIVERGENCES.md) is - split out of it at its size limit; the rule that makes them is there.
A NEW divergence is added at the end of this file marked `proposed <date>, not signed off`, and the marker becomes `signed off <date>` when it is.

**#63 - a function in an object literal names the member it fills** (proposed 2026-10-23, signed off 2026-10-26; rows 83; #105; `src/TsRows/TsDecls/TsWalk.mjs::declareInline`, `TsExpr/TsReadRefs.mjs::fieldTarget`, `TsRefs.mjs::rollupRefIds`): since #104 a literal that is a property value of a contextually typed object literal carries the member's `target` and `target_id`, but a function in the same place did not, so what it returns could not be tied to the member (a `Message: () => cond ? 'a' : 'b'` rule). An inline `functions` row that is such a value - an arrow, a function expression, or a method written in the object - now carries the same `target` `{name, file, line}` and `target_id`, and `returns.member` joins it. Parentheses, `as` and `satisfies` around a value are stepped through for literals and functions alike, so `('x')` and `'x' as const` name their member too. Tables that move: `functions` (`target` and the new `target_id` on inline rows; a `prototype-method` row's `target` is unchanged and gets no id), `string_literals` and `number_literals` (`target`/`target_id` for a wrapped value). No derived table reads them.

**#64 - a function declared in a body is named, and a call of a local holding a function has its callee** (proposed 2026-10-23, signed off 2026-10-26; rows 84; `src/TsRows/TsDecls/TsWalk.mjs::declareInline`, `TsRefs.mjs::rollupRefIds`): a `function inner() {..}` inside a method or function was an inline `functions` row with no name, so the place key of #60 could not find it and a bare `inner(..)` had neither `target_id` nor `callee_id`; and a call of `const twice = (..) => ..` bound the `locals` row with no `callee_id`, though the local's value names the arrow's `functions` row (`$fn_id`). The declaration's row now carries its `name`, and a call of a local or const holding a function has that function as `callee_id`. Tables that move: `functions` (`name` on inline function declarations), `calls` (`target_id`/`callee_id` of such calls), and the derived tables only where a reader follows `callee_id` (`arg_params`, the http pass, the dynamic-render creators, `key_literals`) into the newly reached function.

**#66 - `keyvalue` over an array, a plain class or interface, or what `async` emits hands its value** (proposed 2026-10-23, signed off 2026-10-26; rows 86; `src/TsRows/TsTpl/TsTplHops.mjs::keyValueOf`, `TsTplReads.mjs::fieldsOf`): the framework pipe was typed only over `Record<K, V>`, `Map<K, V>` or an index signature, so `let p of list | keyvalue`, `let p of dto | keyvalue` and `let p of rec$ | async | keyvalue` (or `rec | keyvalue` over `*ngIf="rec$ | async as rec"`) left `p.value` naming nothing. Tables that move: `string_literals`, `number_literals` and `functions` (`target`/`target_id` of such values), and a derived table only where it reads them.

**#69 - a call of a url builder is the url it returns** (proposed 2026-10-23, signed off 2026-10-26; no `rows` bump, the http pass is keyed by the running build; `rust/fbtcore/src/rows/http/calls_helpers.rs::built`; widens #59): #59 read a call whose callee does NOT hand its first argument back as an unknown piece (`*`), so `this.http.get(this.ordersUrl('list'))` over `ordersUrl = (relative) => `${root}orders/${relative}`` - an arrow property or a method - was `*`, and every caller of such a builder lost its path. Tables that move: `http_calls` (`url` more precise: fewer `*`, a builder's path where `*` stood before a suffix) and `http_links` for the rows that now match.
