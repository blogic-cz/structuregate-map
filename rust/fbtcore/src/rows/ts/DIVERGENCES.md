# Signed-off divergences of the Angular half

Split out of [CLAUDE.md](CLAUDE.md), which states what each derived table means.

## The rule that made them

The half replaced a predecessor 1:1, compared by NATURAL IDENTITY (what a row says about the source, never its
id) with every carried field equal. A row the predecessor got wrong was reproduced, and changing it is a
SIGNED-OFF divergence - a port that improves rows cannot be told from one that breaks them. The numbers above
(#1-#11, #13-#15) are those decisions - #13 adds `renders.return_ways` and `render_path.branches`, and moves
`key_reach` only for keys behind such a render; #2 (the atlas reports `routes.children`, `rust/fbtcore/src/atlas.rs`) and #5
(an aliased dependency NgModule, the extractor's) and #12 (`render_graph` leaves out an `out_of_scope` render,
`src/TsRows/TsDerive/TsIndexes.mjs`) live elsewhere. A new restriction is a new divergence: say
which tables gain rows and that no other table moves, and bump the extractor's `rows` (it keys an unchanged tree).


**#21 - a twin enum, a number and a getter's `this.` alias are read** (signed off). Tables that move: `gate_values` (`unknown` becomes `in`/`not_in`, or `in []` for a number no member has) and, for keys under such gates, `key_reach` `always_values` and `unreadable_values`. No other table moves.

**#14 - an input flag the parents bind differently is read per render edge** (signed off; replaces "else unread"
of #11). A way whose edge leaves the flag at a literal `false` is no way. Tables that move: `key_reach`
`always_values`, `always_branches`, `maybe_branches`, `n_paths` and `roots`, for keys under such gates. `gate_values`
does not move.

**#15 - several cases returning one class are either of them** (signed off; replaces "two cases hold nothing" of #13).
Tables that move: `render_path.branches` (an `or:` id) and `key_reach` `always_branches`, `always_values` and
`branch_senses`, for keys behind such a render. `renders` and `gate_values` do not move.

**#16 - a key a template expression chooses holds its arm** (signed off; the template half of #11). Tables that
move: `key_reach` `always_values`, `unreadable_values`, `always_features`, `maybe_features`, `always_branches`,
`maybe_branches`, `branch_senses` and `n_paths` (a key in both arms is two ways), for keys chosen by a ternary, `&&`
or `||` inside a template expression. `gate_values` and `render_path` do not move.

**#17 - an out-of-scope render is no way in** (signed off; #12 for the closure, `closure.rs::load_edges`). A tag
matched to a component the host's NgModule cannot see is no edge, as `render_graph` and `component_reach` already
read it; `unknown` stays an edge. Tables that move: `render_path` (no path through such an edge) and `key_reach`
`roots`, `routes`, `components`, `modules`, `n_paths` and every `always_*`/`maybe_*` column, for keys behind a
same-selector component. A component a module exports from its own file is `imported`, no longer `out_of_scope`
(`renders.scope`, `src/TsRows/TsDerive/TsModuleScope.mjs`).

**#18 - a stronger route never drops another component's site** (signed off; `key/routes/key_routes.rs::put_ways`). The
`route` column stays the strongest route present, but the sites are kept PER COMPONENT, each from the strongest route
that reaches IT: a `literal` or `ts_call` component beside another component's `field_binding` (or a carrier) stays
listed, where the stronger route used to replace the whole site set. A weaker site in a component a stronger route
already reaches is still dropped, so a bare literal's empty gate list never dilutes a position's own `always_gates`.
Tables that move: `key_reach` `components`, `roots`, `routes`, `modules`, `n_paths`, `n_refs` and every `always_*`/`maybe_*`
column, for keys with sites of more than one route in different components; nothing else moves.

**#19 - a method a template calls hands the template the keys it returns** (signed off; the method form of #18's getter).
`{{ label() }}`, `[title]="tip('a')"` read the method's `returns` like a getter's, at the node that calls it (the
receiver's checker-resolved row, never the name), under the node's own `gate_chain`. A method with parameters carries
no branch; one without carries its `if`/`case`. A string literal or ternary of strings argument spells its hole alone.
Tables that move: `key_reach` for keys a template-called method returns (a `ts_call`/`literal` gains the
`field_binding` route and its components); nothing else moves.

**#20 - a dictionary call references every key under its prefix** (signed off; config `i18nDictionaryCalls`): an `i18n_refs` row with `prefix`, no `key`, expanded in `key_routes.rs` against the locale keys under `<prefix>.` (`ts_call`); a field, getter or return HOLDING the call reads as `<prefix>.${rest}` (`key_follow::dictionary`, `field_binding`); a converter's argument is not followed. Moves: `i18n_refs` (new), `key_reach`.

**#22 - a key behind a pushed list, a template hole, a chained string method or a dynamic index reaches the field** (signed off; #19's readers skipped them): no condition carried, a field list's push carries its branches. Tables that move: `key_reach` for keys behind these shapes, `i18n_refs` (a call indexed so claims every value), `value` JSON of `returns`/`locals`/`assignments`/`calls` (`$hole_values`, `$receiver_value`, `$indexed`; `rows` 41).

**#23 - more shapes reach the field** (signed off; #22's readers skipped them): a `+=` on a returned local, an `await <call>`, a field a `.then` callback writes its parameter to, a list copied by `slice`/`map` (parameter kept), a const ARRAY read by an unknown index, an arrow property a template calls, a list every parent binds to a child's `@Input`. Tables that move: `key_reach` for keys behind these shapes, `value` JSON of `returns`/`locals`/`assignments`/`calls` (`$indexed` on arrays; `rows` 42).

**#24 - a key a class instance carries reaches the field that reads it** (signed off; #19-#23's readers stopped at the class a receiver is declared by): `this.c = this.btn.text` and `this.c = this.strat.tip()` read the member of the receiver's class, and of every subclass or implementer a `new` builds (`key/fields/key_classes.rs`; an unbuilt one contributes nothing), a constructor's `this.<member> = ..` write included; no callee branch carried. A call through a receiver is now entered by the class the checker declares it in (`$owner`), where two members of one name in a file read as none. Tables that move: `key_reach` for keys behind these shapes, `value` JSON of `assignments`/`returns`/`locals`/`calls`/`members` (`$owner` on a call, `$read` on a property read through a receiver; `rows` 43). It reaches lists of instances too: pushed with `new X(..)` in a parent (a local handed to the field, a field push, either inside a `.then` callback) and handed to a child's `@Input`, read in the child's `*ngFor` as `b.text` or `b.tooltip.text(row)`; a `.push` inside a callback now counts for the member's class (`key_pushes`), and a template call on an interface or base method reads every built subtype's. Moves also `key_reach` for keys behind lists filled by a push in a callback.

**#25 - a list of instances reaches the child's table through the shapes a real one is built and handed with** (signed off; #24's readers stopped at a field holding the list): a callee's returned local and its pushes (in its callbacks too), a pushed `const` of a `new`, `push(...call())`, a constructor write inside a callback, every return a held function spells, an `@Input` setter copying into a field read through its getter, an input bound to a call, a getter or a property of a field (`cfg.list`), a method the template hands the loop item to (`$reads` off its parameter), a template read of a base's or an interface's property, and a field an rxjs `subscribe` (through value-passing `pipe` operators) or a `Promise.resolve(x).then` callback writes from its parameter, and a `this.<x>` write two classes of one file both declare `x` for (resolved through the writing class). A key a list element holds through a call (a callee's list of `{ label: t('k') }`) now keeps the element's own chain - the write's branches, the edge - where it used to drop it. A CHILD'S INPUT IS NOW READ PER RENDER EDGE (`edge:<render>`): #23 required every parent to bind a known list, and one parent rendering the child without it left every key of every parent unreached. Tables that move: `key_reach` for keys behind these shapes, `value` JSON of `calls` (`$spread` on a spread argument) and of `assignments`/`members` (`$fn_id` on a function held in place; `assignments.holder`; `assignments.target_id` on such a write; `rows` 44).

**#26 - a callee's branch on its parameter restricts a key by the caller's argument** (signed off; #19-#25 carried no condition of a callee): a field or getter holding `this.svc.f(this.item.kind)` gets `arg:<branch>@<call>` on each key `f` returns under its own `if`, the condition being the branch with `f`'s parameters replaced by the call's arguments (`key/fields/key_args.rs`, sense of the branch); a method a template calls holds `arg:<branch>@<call>@<template expression>`, its parameters replaced by the template's arguments at that call (#48 extends it to every call between the field and the key). A local arrow or handed-in function is now entered before its call is read as an `i18nCalls` call - a local `t` wrapping the translate call no longer reads as one. Tables that move: `key_reach` (`always_values`, `always_branches`, `maybe_branches`, `branch_senses`, `n_paths`) for keys a service returns under a branch on a parameter; keys behind a local arrow named like a translate method.

**#27 - extractor rows the original tool left out** (signed off 2026-10-18; `rows` 45): `on()` handlers spread into `createReducer` from a const array (same file or imported) and selector factories (`state_selectors.factory`); `di` rows for `inject()` fields and the token of `@Inject(TOKEN)` (`token`, `token_ref`, `token_id`); an `export { A as B }` alias resolved to `A` (`routes.component_id`, `ng_modules` refs' `id`, `component_reach`); a static attribute filling an input (`input_usage` with `expression` null, `io.bound_count`); `imports` rows for a bare `import()` / `require()` (`dynamic`); interfaces and type aliases inside a module block (`in_module`), and a non-ambient namespace's classes, functions and consts. Tables that move: those named; nothing else.

**#28 - a reference through an alias the module file imports, and where an import lands** (signed off 2026-10-18; `rows` 46): an `ng_modules` ref or a route's `component` that names an `import { A as B }` alias, or that the evaluator left unresolved (`{expr}`), joins the class through the file's own `import_names` row (`id`, `component_id`); `imports.in_tree`; `in_module` on a namespace's classes, functions, consts and enums. In the key closure: a bare parameter a callee hands on (`this.home(name)`) carries the caller's string, and a caller's plain `const` local in a carried condition is the chain it holds. A shorthand property (`{ template }`) evaluates to its const's value (`class_decorators.args`, every object literal), and a same-file const-held inline template takes the const's line (`components.inline_template_line`; an imported const keeps the decorator's). Tables that move: those named, and `key_reach` for keys behind these shapes.

**#29 - `[hidden]` hides, so it gates on its negation** (signed off 2026-10-18; `rows` 46): `[hidden]="c"` / `[attr.hidden]="c"` is a `gates` row with `gate_kind = 'hidden'` whose `expression` is a row holding `!(c)`; a key in its element or subtree is restricted to the members `c` excludes (`not_in`). Before, it was no gate, or a `gateInputs` `declared_input` read as `in` - the wrong side. Tables that move: `gates`, `expressions` (one row per `[hidden]`), `gate_values`, `key_reach` for keys under one.

**#30 - a class gate restricts only when a stylesheet proves its class hides, and then on the false side** (signed off 2026-10-18): `[class.x]="c"` whose class has a `class_hides` row (scope `own`/`shared`) is read as `!c` (the element shows while `c` is false); a class no rule proves hiding is no visibility condition and gives no `gate_values`/`gate_features` row (it stays in `gates`/`always_gates`). The stylesheets are now read before the closure (`tsapply.rs`). Before, every class gate was read as `c`: the wrong side for a hiding class and a false restriction for a styling one. Tables that move: `gate_values`, `gate_features`, `key_reach` for keys under a class gate.

**#31 - a literal inside a component class is a site of that component only** (signed off 2026-10-18): a bare literal equal to a key, written inside a component's class, is a `literal` site of that component, not of every component in its file; one outside any class or in a non-component class still is. Before, a child's own `key = 'a.b'` in a file shared with its parents was an ungated site of each parent, and the child's template gate no longer restricted the key. Tables that move: `key_reach` for such keys.

**#32 - `state_effects`, and a `createEffect` callback's body is walked** (signed off 2026-10-18; `rows` 46): the arrow handed to `createEffect` was never walked (a property is walked only when it is itself a function), so `ofType(a, b)` existed as `$fn` text only. Its calls, returns and nested arrows are now rows under the effect member, and `state_effects` names the actions each effect listens to, whether it dispatches and what its callbacks return. Tables that move: `state_effects` (new), `calls`/`functions`/`returns`/`locals`/... for effect bodies.

**#33 - an input's dimension is the parent's expression on a way through its binding** (signed off 2026-10-18): On a way through a render edge that binds a child `@Input` to a plain, non-constant read chain the child never writes, the two spellings (`vm.kind`, `item.kind`) are one variable ON THAT WAY: every row keeps its own text, and rows present under both intersect. Rows under aliased texts that come out equal on every way are published once, labelled by both. Renaming either spelling into the other split one variable wherever only some rows were renamed: renaming the child up (v2.1.13) and renaming the parent down (not released) each lost keys a real tree restricts. A constant (a literal, or a chain through a `typeof X` alias field) aliases nothing (#49). Tables that move: `key_reach` `always_values`/`unreadable_values` for keys under such edges.

**#34 - a callee branch carried through a call is one dimension of the callee's parameter** (signed off 2026-10-18): a callee branch carried through a call (`arg:`) restricts the callee's PARAMETER: when its condition reads one parameter, its rows are one dimension on every way, keyed by (callee, parameter), and published under the caller spellings joined. Before, each spelling was its own dimension, so ways that spelled the argument differently left none common and the fold widened it (#48). Tables that move: `key_reach` `always_values`/`unreadable_values` for keys carried through a call reached by differently spelled arguments.

**#35 - a parent that only hands a list to a child's input is no site of its keys** (signed off 2026-10-18; `key/routes/key_routes.rs::Routes::claim`): a key held by a list element that reached a child's `@Input` through a render edge (`edge:<render>`) drops the edge parent's weaker (`ts_call`, `literal`, `route_path`) site of that key; a site of the parent's own at the template rank stays. Tables that move: `key_reach` `components`, `roots`, `modules`, `routes`, `n_paths`, `n_refs`, `min_depth` and every `always_*`/`maybe_*` column, for keys built in a parent and displayed through a child input; nothing else moves.

**#36 - a key inside an `ng-template` only outlets render takes the outlets' gates** (signed off 2026-10-18; `key/routes/key_outlets.rs`, `key_routes.rs::put_sited`): a site inside `<ng-template #ref>` whose every read is an outlet binding (`[ngTemplateOutlet]`, `*ngTemplateOutlet`, `then`) holds one way per outlet, the outlet's chain without its hand-over gates; before, it held only its lexical chain and an outlet's `*ngIf` restricted nothing. Tables that move: `key_reach` `always_gates`, `maybe_gates`, `always_values`, `unreadable_values`, `always_branches`/`maybe_branches` and `n_paths` (one per outlet way), for keys inside such templates; nothing else moves.

**#37 - a constant `false` drops a way only through a gate that hides** (signed off 2026-10-18; `key/key_bound.rs`, `key_dead::renders_at_false`): an edge whose binding (or literal initializer) folds a child's gate to `false` is no way only when that gate is `*ngIf`, an `@if` branch, `[hidden]`/`[attr.hidden]` or a class a stylesheet proves hiding. Before, any gate did, so `[disabled]="isDisabled"` (a `gateInputs` `declared_input`) with a parent binding `[isDisabled]="false"` removed that parent's way and restricted the key to the other ways' values. Tables that move: `key_reach` `n_paths`, `roots`, `min_depth`, `always_*` (shrink) and `maybe_*` for keys behind such a gate; `gates`, `gate_values` and `render_path` do not move.

**#38 - `key_reach.paths` names each way** (signed off 2026-10-18; `key/keyreach.rs::ways_of`, `closure.rs::Paths::first_id`): one `{path, own}` per way, `n_paths` of them, `path` a `render_path.id` and `own` what the way adds to that row's `gates`/`branches`. Tables that move: `key_reach` gains `paths`; no other column or table moves, and no restriction changes.

**#39 - the template nodes and expressions of later compilers are read** (signed off 2026-10-18; `src/TsRows/TsTpl/TsTplExtract.mjs`, `TsTplExpr.mjs`, rows 48). On a v21+ compiler an `@switch` case's content sits under its case again (a fall-through group under none of its cases); `@let` publishes its expression; `@for` `context_vars` are names, not indices; `@defer` publishes its `when` expressions, `hydrate_triggers` and `trigger_refs`; an ICU's interpolations are rows; `@for` and `@if … as` rows carry `variables`, so a read of a block-bound or `@let` name resolves to no component member and an `@for` item is typed from its collection (`expressions` read `target`s move); on v20+ an assignment is a `Write` again and an arrow parameter's read is no read. On EVERY compiler `-a` is a `Unary` reading `a` (it was a `Binary` with no operands). Tables that move: `template_nodes` (rows and columns), `expressions` and their `template_strings`/`i18n_refs`, `gates` and `gate_chain` under `@switch` (v21+), and through them `gate_values` and `key_reach` for keys under such gates; `renders` and `bindings` do not move.

**#40 - an `@switch` case restricts its switch as `*ngSwitchCase` does** (signed off 2026-10-18; `gate/gate_switch.rs`): a `block` gate `SwitchBlockCase` is the arm of the nearest enclosing `SwitchBlock` gate's node (its parent, or its grandparent through a fall-through `SwitchBlockCaseGroup`), read by the same `switch_arm`: `in [member]` when the case names a member of the discriminant's enum, `unknown` otherwise. `@default` has no expression and so no gate: unrestricted, as `ngSwitchDefault`. Before, an `@switch` gave no `gate_values` row, so a key one case alone renders read as shown for every member. Tables that move: `gate_values` (a row per `@case` gate) and `key_reach` `always_values`/`unreadable_values`/`maybe_*` for keys under an `@case`; no other table moves.

**#41 - an `@for` over a list of objects is a loop as `*ngFor` is** (signed off 2026-10-18; `key/key_loops.rs::Loops::new`): an `@for` is no `ngForOf` gate (its own `ForLoopBlock` gate is #43), so the loop is its `ForLoopBlock` node, its collection the `block_ForLoopBlock` expression on that node and its item the node's `$implicit` variable. A key in the list read as `item.prop` inside the block is a site at that node (`key_reach` `components`/`n_refs`/`routes` and every `always_*`/`maybe_*`), and a directive config over `item.prop` is read per element (`gate_values` for that gate; `key_reach` `always_branches`/`always_values` gain `loop:<gate>#<i>`). The link names the gate that READS the item, never the loop, so a block loop's link is the same `loop:<gate>#<i>` as an `*ngFor`'s. Before, every such key stayed the class's `literal` site, ungated. Tables that move: `key_reach` and `gate_values`, for keys and config gates inside an `@for`; no other table moves.

**#42 - an `@if … as` / `*ngIf … as` alias is typed from its condition** (signed off 2026-10-18; `src/TsRows/TsTpl/TsTplReads.mjs`, `rows` 49): an alias of a condition that IS a read chain (`owner`, `row.owner`, `owner!`) or a pipe over one (`owner$ | async`, a map pipe's own `transform` type first) is bound to that chain's declared type, every hop resolved; a condition that tests or calls something types nothing. Before, every alias bound to nothing, so `{{ o.title }}` resolved no `target`. Tables that move: `expressions` (`ast` read `target`s through an alias) and, through those targets, `gate_values` dimensions and `key_reach` for gates reading an alias; no other table moves.

**#43 - an `@for` collection is a gate, and `@empty` sits beside its loop** (signed off 2026-10-18; `src/TsRows/TsTpl/TsTplExtract.mjs`, `gate/gate_features.rs::ITERATION_GATES`, `rows` 50): the `block_ForLoopBlock` expression is a `gates` row (`gate_kind = 'block'`, `name = 'ForLoopBlock'`), read like `*ngFor`'s `ngForOf`: an iteration gate for `gate_features` (a list a feature fills with `c ? [..] : []` requires the feature), not hiding at a literal `false` (`key_dead`, `key_bound`). `@empty` shows exactly when the collection is empty, so it is now the `@for` node's sibling (its parent, its depth), outside that gate and outside the loop's sites. Before, an `@for` was no gate, so a key inside it had no loop gate in `always_gates` and lost the iteration feature, and `@empty` was the loop's child. Tables that move: `gates`, `expressions.gate` for `block_ForLoopBlock`, `template_nodes` `gate_chain`/`gate_depth` inside an `@for` and `parent`/`depth`/`order` of `@empty`, `gate_values`/`gate_features` rows for the new gate, and `key_reach` (`always_gates`, `maybe_gates`, `always_features`, `maybe_features`, `always_values`/`unreadable_values` and `render_path`/`paths` where a component is rendered inside an `@for`) for keys inside an `@for`; no other table moves.

**#44 - a component field nothing reads is no site of the key its initializer holds** (signed off 2026-10-18; `key/routes/key_unread.rs`, `key_routes.rs` step 5, `rows` 51): a string literal that initializes a field of a component class (`labelCode = 'k'`) is no `literal` site of that component when nothing can read the field: no template expression resolves a read to the member, no unresolved read or string literal spells its name, no file reads a property of that name (`files.prop_reads`), the member carries no decorator, and the file never hands `this` to anything but a `this.x` read or `.bind`/`.call`/`.apply` (`files.this_indexed`). Before, every such initializer was an ungated way through its component, and a key another component renders under a gate lost its restriction. A plain `=` write to the name through `this` is not a read (#68), in the member's own file or in another (a sibling class of one shape writing its own `this.f`); one through any other receiver (`notice.f = 'k'` on an instance a factory made) stays a read, and its literal a site: the literal a `this.f = 'k'` to such a field writes is no site either, nor is a literal an unread GETTER returns (`get t() { return 'k'; }`), nor an arm of a ternary of strings that is such a statement's whole value (`return c ? 'a' : 'b'`); a literal inside a call or condition of such a statement stays a site. The #18 case `TsRowsKeyFunctions` held its weaker `literal` site in such an unread field (`readonly key = 'k'`); it now reads the field, which is the shape #18 is about. Tables that move: `files` gains `prop_reads` (`{name: count}`) and `this_indexed`; `key_reach` `components`, `roots`, `modules`, `routes`, `n_paths`, `paths`, `n_refs`, `min_depth`, `route` and every `always_*`/`maybe_*` column for keys held by such a field; no other table moves.

**#45 - a branch around the call of a private method holds inside it** (signed off 2026-10-18; `key/routes/key_called.rs`, `closure.rs::load_edges`, `key/key_branches.rs::literal_ways`, `key_routes.rs` step 3): a component created in code (`renders.call`) renders under the creating call's own chain, and under what every call of the method holding it holds when that method is `private`, no `ng*` lifecycle hook, undecorated, and every read of its name in the tree is a `calls` row resolved to it (no template, string or other file reads it; its file's `prop_reads` count equals its callers; `this_indexed` 0) - the intersection over callers, each caller's chain joined to what its own method lifts. A key a `ts_call`, literal or pipe site reaches inside such a method holds the same. Before, a render edge held only a factory's `return_ways` and a key only its own member's chain, so `if (c) { this.openModal(); }` restricted nothing. Tables that move: `render_path.branches` (and `render_path` rows' ids), `key_reach` `always_branches`, `maybe_branches`, `branch_senses`, `always_values`, `unreadable_values`, `paths` for keys behind such calls; no other table moves.

**#46 - a guarded method a gate calls, and a ternary in truth position** (signed off 2026-10-18; `gate/ts/gate_props.rs`): a method of no parameter whose one non-`false` return sits under a top-level `if (C)` and every other return is the literal `false` is `C && E` where a gate (or a property it defines) CALLS it, both ways - as such a getter already was; a bare read of the method (a function, always truthy) is never replaced. A `const` local tested as that `C` (or a getter's) is its initializer. An `E` that is a bare read chain (`return this.detail?.Gift;`, #66), which the extractor keeps no tree for, is spelled back as that chain; before, the whole definition was dropped and `C` with it. A SET dimension in `key_reach.always_values` keeps the side its rows were written on, as `gate_values` does (#66: `modelKinds in [Flat, Home]` had been published as `not_in [Life]`, and "holds some of" is not "holds none of"); ways written on different sides, and every scalar, keep the smaller side. A ternary `c ? a : b` in truth position (a gate, a property's definition, either side of `&&`/`||`, under `!`) is `(c && a) || (!c && b)`: the OR's union of its sides, so `c ? isHome(..k) : isFlat(..k)` permits `k in [Home, Flat]` - the honest answer only because `c` restricts no dimension of `k`; where `c` itself restricts a dimension both of its sides hold it, and a dimension only one arm states is no row. Before, either shape gave no `gate_values` row. Tables that move: `gate_values`, `gate_features` and `key_reach` (`always_values`, `unreadable_values`, `maybe_*`) for gates behind such a call or ternary; no other table moves.

**#47 - a filter or a slice of a list a callee returns hands back what the list holds** (signed off 2026-10-18; `key/fields/key_follow.rs::Returned::through`): a return `[this.home(m)].filter(..)` (or `.slice(..)`) over a list literal is followed through the list, as `key_lists::list_of` already read it for a loop; before, the call stopped the follow and a key reached only that way read `literal`, `n_paths 0` - rendered for nobody.
